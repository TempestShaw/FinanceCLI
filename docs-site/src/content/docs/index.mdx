## Why This Exists

You can already combine notebooks, yfinance, SEC downloads, PDF parsers, spreadsheet formulas, and backtesting libraries by hand. That works until every company or question needs a slightly different glue script.

Finance CLI packages those recurring research steps into terminal commands with consistent JSON output. The goal is not to hide the underlying sources. It is to make common research moves easy to repeat, inspect, diff, and automate.

## Use-Case Reference

If you know the research job but not the exact command, start from the [Namespaces](/FinanceCLI/namespaces/) page. It groups commands by setup, filings, market discovery, evidence gathering, calculators, and backtesting.

## Machine-Readable Entry Points

| File | Use it for |
| --- | --- |
| [`llms.txt`](/FinanceCLI/llms.txt) | Compact LLM entry point and read order. |
| [`llms-full.txt`](/FinanceCLI/llms-full.txt) | Full command routing context and playbooks. |
| [`tools.json`](/FinanceCLI/tools.json) | Command schemas, side effects, citation fields, and agent routing hints. |
| [`openapi.json`](/FinanceCLI/openapi.json) | OpenAPI-style adapter contract for MCP/plugin wrappers. |
| [`finance-cli-skills.zip`](/FinanceCLI/skills/finance-cli-skills.zip) | Skill package for agents that support local skills. |

## Install

```bash
python -m pip install -U finresearch-cli
```

The default install includes SEC filing access, PDF parsing, Camelot table extraction, PaddleOCR fallback, Yahoo market data, finance formulas, and VectorBT backtests.
